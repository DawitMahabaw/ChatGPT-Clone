# ChatGPT Clone with MVC

A simple full-stack ChatGPT-style application built as a learning project.

The project uses the provided React frontend and a Node.js/Express
backend built from scratch using the MVC architecture.

The application allows users to send questions, receive AI-generated
answers, and store conversations in a MySQL database.

---

## 🎯 Project Goal

The main goal of this project is to understand how a full-stack
application works from the frontend to the backend.

This project is also used to practice:

- MVC architecture
- REST APIs
- React
- Node.js
- Express
- MySQL
- Gemini API
- Git and GitHub
